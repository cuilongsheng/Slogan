# Deployment Runbook

For the first free browser preview, use the [free preview deployment guide](../deployment/free-preview-deployment.md). It records the confirmed `main` branch, Cloudflare Pages / Render / Neon resource steps, code prerequisites, configuration boundaries, migrations, acceptance, and rollback preparation. Resources have not been created or deployed.

The formal production environment and CI release mechanism remain undecided. Preview preparation does not turn pending implementation or platform compatibility into production evidence.

Do not claim production deployment from local builds, tests, documentation, or an archived OpenSpec change.
