## Runtime configuration

The actual email link needs to make the backend `EMAIL_VERIFY_URL` point to `/email/verify` and `EMAIL_RESET_URL` point to `/email/reset`; the two front-end pages only read a single token through the link fragment and immediately clear the address bar in the browser. The production environment must use a trusted HTTPS domain name, and the backend needs to be configured with SMTP, keys and `EMAIL_PASSWORD_AUTH_ENABLED` first.
