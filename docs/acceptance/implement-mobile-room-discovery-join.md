## Design discrepancies and contract gaps

- There are no corresponding available API fields for the member avatars and list of the design draft, the total number of rooms on the server, and language filtering. The page displays the loaded number and real room host text, and does not render the sample avatar. The list only shows the "All" filter appearance.
- The "Find Partner/Message/Mine" and Create Room icons at the bottom of the design draft are currently only disabled visual portals, and the corresponding functions require respective changes; the currently available portal is "Discover".
- The page language follows the device language; `zh-CN` Playwright preview has been used to compare the Chinese original, and the copywriting line wrapping of the real Chrome English session still changes with the language.
- The main operation of the device page is changed to "Check Microphone", and it is clearly stated that the room has not been entered or the quota has been occupied because the voice room client has not yet been delivered.
- For native devices, if the system prohibits asking for microphone permission again, the page displays the settings entry; Web rejection and no device are still classified separately. Release web audio track after checking without starting room live session.

This batch has completed the room discovery and room preparation pages. The device page must clearly state that it has not been actually joined; the membership or real-time credential interface cannot be called, nor can the page preview be called an available voice room.
