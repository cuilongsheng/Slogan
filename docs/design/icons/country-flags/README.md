# Country flag SVGs

`4x3/` contains **249 SVG flags** indexed by the ISO 3166-1 alpha-2 country or region codes in `manifest.json`. Use the member's explicit country code to choose a flag; do not infer it from their name, language, or location text. If no supported country code is available, leave the flag slot empty.

Source: [lipis/flag-icons](https://github.com/lipis/flag-icons), commit `086f7e97d657358203916dbe84f61c2bccaa81eb`. The upstream `country.json` entries with `iso: true` were copied from `flags/4x3/`. The [MIT license](LICENSE) is included for redistribution. This collection covers ISO countries and territories, not only sovereign states; upstream also has 22 non-ISO flags that are intentionally excluded.

These files are local design assets. The full set has **not yet been imported into Figma** because the Desktop Bridge disconnected during that step. The six flags previously shown on the voice-room mockup remain illustrative until they are replaced with this code-indexed set.
