# Slogan SVG icons

This folder contains **54 original, editable SVG icons** for the Slogan design system. Each uses a 24 × 24 viewBox, rounded 1.8 px outline, and `currentColor`. Run `python3 docs/design/icons/generate.py` to regenerate the files.

The matching Figma vector components are in [00 Foundations → SVG Icons / V1](https://www.figma.com/design/56nIowZmvBhb0QJvOlDQdU/Slogan?node-id=105-1058). The mobile room list, voice room, and admin safety draft use instances from this set where relevant.

## Coverage

- Navigation and utilities: add, arrow-left, more, compass, room, message, user, users, search, filter, chevron-down, history, settings, bell, help.
- Room and voice: mic, mic-off, waveform, headphones, hand, leave, share, send-up, lock, clock, crown, link, copy, refresh, network-off, user-remove, play, pause, record, stop.
- Safety and admin: info, flag, shield, warning, error, ban, appeal, dashboard, file-text, role, audit, sort, export, external-link, eye, check, close, calendar, sparkles.

## Product assets and decisions

No generic icon is currently blocking the three pilot pages. These are **product assets**, so an icon site is not an automatic substitute:

1. Slogan's final brand mark and any VIP/creator badge artwork.
2. Country/region flag usage is now backed by the [249-file ISO flag set](country-flags/README.md). The current Figma mockup still has six illustrative flags; bind displayed flags to actual member country codes when the Desktop Bridge is available.
3. Real avatar images or a product-approved avatar illustration set.
4. Optional room-topic illustrations, gifts, or animated reactions if those features are approved.

Before using any downloaded asset, check its license and match the 24 px grid, rounded stroke, and optical weight of this set.
